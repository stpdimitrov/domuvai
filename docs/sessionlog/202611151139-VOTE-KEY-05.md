**Did** — `POST …/paper-decisions` requires an `Idempotency-Key` (a missing header is a 400; a blank key is a 400 after the policy check). `PaperDecisions.record` is now transactional. After the policy check and the record's own validation, `VoteRequestKeys.decide` (the kernel's `decideKey`) checks what the entrance kept for the key. A new key keeps the key and the record in one transaction, and the record names its key (`paper_decision.request_key_id`). The same key with the same request (entrance, who records it, text, date, reference, archive location, custodian, as stored) writes nothing and answers 201 with the record it first made.
