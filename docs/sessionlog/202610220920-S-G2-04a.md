## S-G2-04a · 2026-10-22 · evidence — documents stored immutably, versioned, typed (PM-DOC-001, PM-DOC-002, PM-DOC-007)

**Did** — the `evidence` module begins: `zues.app.evidence.Documents` stores a statutory document and reads it back (`store`, `find`, `versions`, `content`), and publishes `DocumentStored`. The bytes are content-addressed in a new `evidence.blob` table, and the database itself checks the SHA-256 against the bytes. A re-upload is a new row naming the version it supersedes: same entrance, entity and kind, one successor per version, and the first version's id shared as `document_key`. Neither table can be changed, removed or truncated. The kind is one of the six the rule names. A protocol is refused without its paper's location and custodian. No HTTP endpoint and no caller yet.
